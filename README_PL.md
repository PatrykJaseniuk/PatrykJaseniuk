# Patryk Jaseniuk

**Fullstack (Full Stack) TypeScript Developer** — React · Node · PostgreSQL · agenci LLM

Buduję aplikacje w TypeScripcie end-to-end: model danych, API, UI, testy, CI. Rozwijam je
z agentami LLM — piszę kontrakty, które agent może wykonać, i bramki, których nie może obejść.

## Projekty

**[Webapp1](https://github.com/PatrykJaseniuk/Webapp1)** — szablon fullstack: React + TypeScript
na Supabase, PostgreSQL RLS jako jedyna warstwa autoryzacji, 200+ testów Vitest, E2E w Playwright,
pgTAP, CI z 7 zadaniami.

**[ParysWeb2](https://github.com/PatrykJaseniuk/ParysWeb2)** — strona siłowni + typowany model
treści (Astro 5): CMS w JSON → generowane typowane moduły, bramki spójności przy każdym buildzie,
audyt Lighthouse. → [parys.nysa.pl](https://parys.nysa.pl)

**[StatkiTS](https://github.com/PatrykJaseniuk/StatkiTS)** — symulator żaglowca 2D z silnikiem
fizyki napisanym ręcznie — bez agenta i bez biblioteki fizycznej: soft-body kadłuba, siły wiatru
i wody, kolizje, 55 testów Jest.

**[pkg-builder](https://github.com/PatrykJaseniuk/pkg-builder)** — warsztat, w którym agent LLM
buduje oprogramowanie ze źródeł: kontrakt `AGENTS.md`, niemutowalny DAG wartości, 23 pakiety,
6 launcherów.

## Jak pracuję

- **Domyślnie funkcyjnie** — niemutowalne dane, funkcje wyższego rzędu, kompozycja zamiast mutacji.
- **Typy jako dokumentacja**, testy i CI jako bramka — dla ludzi i dla agentów.
- **Agenci:** DSH jako mój harness, DeepSeek v4.1-Flash, lokalnie Qwen 3.8; MCP i skille jako kontekst.
