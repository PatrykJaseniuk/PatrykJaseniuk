# Patryk Jaseniuk

**Fullstack TypeScript developer** — React · Node · PostgreSQL · agents

I build TypeScript apps end to end — data model, API, UI, tests, CI — and develop them
with LLM agents: contracts the agent can execute, gates it cannot bypass.

## Projects

**[Webapp1](https://github.com/PatrykJaseniuk/Webapp1)** — fullstack template: React + TypeScript
on Supabase, PostgreSQL RLS as the only authorization layer, 200+ Vitest tests, Playwright E2E,
pgTAP, a 7-job CI pipeline.

**[ParysWeb2](https://github.com/PatrykJaseniuk/ParysWeb2)** — gym site + typed content model
(Astro 5): JSON CMS → generated typed modules, consistency gates on every build, Lighthouse
audit. → [parys.nysa.pl](https://parys.nysa.pl)

**[StatkiTS](https://github.com/PatrykJaseniuk/StatkiTS)** — 2D sailing simulator with a physics
engine written by hand — no agent, no physics library: soft-body hull, wind and water forces,
collisions, 55 Jest tests.

**[pkg-builder](https://github.com/PatrykJaseniuk/pkg-builder)** — workspace where an LLM agent
builds software from source: an `AGENTS.md` contract, an immutable value DAG, 23 packages,
6 launchers.

## How I work

- **Functional by default** — immutable data, higher-order functions, composition instead of mutation.
- **Types as documentation**, tests and CI as the gate — for humans and agents alike.
- **Agents:** DSH as my harness, DeepSeek v4.1-Flash, Qwen 3.8 locally; MCP and skills for context.
